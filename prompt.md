

## 🔷 CORE REQUIREMENT

* All prices must be displayed in Indian Rupees (₹)
* Currency format must follow Indian system (e.g., ₹1,999, ₹10,500)

* UI/UX should feel like Flipkart + Myntra (clean, colorful, modern)
